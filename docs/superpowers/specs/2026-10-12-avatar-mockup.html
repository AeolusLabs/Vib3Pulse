Plan

How it gets built

Phase 1

Avatar core

  • avatar JSONB on users: type, skin, hair, hairColor, expression, facialHair, outfit, outfitColor, eyewear, headwear, hoops
  • One <Avatar config mode/> SVG component used everywhere
  • Editor page and onboarding step
  • Photo or initials fallback
Phase 2

Map pins

  • Friend markers render the badge via divIcon
  • Avatar config added to the friends payload through toPublicUser()
  • Lookout and tickets reuse the component
Phase 3

Buildings

  • buildingStyle and accentColor on venues and events
  • Picker in the create modals
  • Building markers with verified glow
Phase 4 · later

Party rooms

  • Own spec. Config slots carry over
  • Poses and walk cycles layer on top
  • Wardrobe store and unlocks
